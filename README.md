# 집의 시간: 연도별 주택 선택

2026~2030년에 매년 한 번 선택하고, 2031년에 마지막 결과를 확인합니다. 첫 해부터 현금 보유가 가능합니다. 교사가 2026→2027을 시연하고 학생이 나머지를 진행할 수 있습니다.

실제 단지 610개와 2020년 1~9월의 가격 표본을 시작점으로 활용합니다. 시나리오와 2021년 이후 가격은 가상이며 2026년 실제 시세가 아닙니다.

## 실행

```bash
python -m http.server 8000
```

http://localhost:8000 에 접속합니다. `map-config.js`에 JavaScript 키가 있으면 카카오 지도, 없으면 기본 지도를 사용합니다. 본인 키를 외부에 공개할 때는 카카오 플랫폼 도메인 설정을 확인하세요.

## 자료와 계산

- `data/classroom-scenario.json`: 2026~2030년 가상 정책·뉴스·지역 수요·공급·생활권 프로젝트.
- `src/market-model.js`: 구매력, 수요, 공급으로 매년 가격 변화 계산.
- `src/finance.js`: 매년 12개월의 대출·저축·임차비·손익 계산.
- `src/views.js`, `styles.css`, `classroom.css`: 화면 구성과 스타일.
- `src/game.js`: 현금 보유·매수·보유·매도·갈아타기.

`fifth`의 2026·2028·2030 시나리오를 바탕으로 2027·2029년 값은 선형 보간한 가정입니다. 연간 입주량은 기존 2년 합계의 절반, 수요의 기본 효과와 지역 프로젝트 효과는 2년 기준의 절반으로 설정했습니다. 금리·대출 한도 변화 효과는 각 해의 정책 변화량을 사용합니다. 이 계수와 값은 예측이나 실증 추정이 아닙니다.

새 저장 키를 사용하며 이전 게임의 저장값과 분리됩니다.

```bash
node tests/check-model.cjs
```
