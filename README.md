# 집의 시간 — 미래 주택 선택 수업

`fifth`의 현재 버전은 **2026–2032 미래 가상시장**입니다.

- 2026·2028·2030년에 결정하고, 매번 24개월 뒤 결과를 확인합니다.
- 2032년에는 추가 거래 없이 결과를 돌아봅니다. 총 3회 결정, 6년입니다.
- 실제 단지 610개의 위치·면적·준공연도와 과거 가격 표본을 활용합니다.
- 2020년 1–9월 표본 중앙값을 **금액 보정 없이 게임 시작가격**으로 재사용합니다. 2026년 시세를 추정한 값이 아닙니다.
- 금리·정책·뉴스·수요·공급·거래 예시·미래 가격은 수업용 가정입니다.

## 실행

`index.html`을 Live Server로 열거나, 프로젝트 폴더에서 다음을 실행합니다.

```sh
python -m http.server 8517 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8517/`을 엽니다. 지도와 웹 폰트에는 인터넷 연결이 필요합니다. 기본 지도는 OpenStreetMap이며 `map-config.js`에서 선택적으로 Kakao JavaScript SDK 키를 설정할 수 있습니다.

## 수업 진행

1. 학생이 가상 인물을 고르고 자금 조건을 확인합니다.
2. 교사가 2026→2028 한 라운드를 시범으로 보여줍니다.
3. 학생이 정책·뉴스·매물을 비교하며 나머지 라운드를 진행합니다.
4. 2032년 결과에서 선택 이유와 예상이 달라진 지점을 설명합니다.

뉴스와 매물의 상세 근거는 접어서 제공하고, 거래 선택은 화면 아래에 유지합니다. 결과는 부동산 손익(집값 증감−이자−거래비용)을 먼저 보여주고, 소득에서 모은 저축과 임차 주거비는 분리합니다. 전체 순자산은 결과 상세에서 확인합니다. 동별 입주물량·비율과 같은 구·시의 다른 동을 비교할 수 있고, 결과 상세에는 선택 전후 금액이 표시됩니다.

8개 생활권 시나리오를 반영해 같은 기간에도 상승·하락 지역이 섞입니다. 공급사업은 화면의 입주물량에 반영되며 그 비율을 가격 계산에 그대로 사용합니다. 보완된 시나리오는 v2 저장 공간에서 새 게임으로 시작하고, 이전 v1 기록은 덮어쓰지 않습니다.

## 수정 위치

| 파일 | 내용 |
|---|---|
| `data/classroom-scenario.json` | 3개 기간 정책·뉴스·지역 수요·공급·생활권 프로젝트와 참고 출처 |
| `data/listings.json` | 기존 610개 단지와 2020년 기준가격 자료 |
| `src/state.js` | 기간 상수·페르소나·버전별 저장 |
| `src/market-model.js` | 구매력·수요·공급의 2년 가격 변화와 요인 설명 |
| `src/finance.js` | 대출 한도·24개월 상환·예산 미리보기·회계 검증 |
| `src/game.js` | 매수·보유·매도·갈아타기·2년 진행 |
| `src/views.js` | 접기 구조·지도 옆 상세·정책·결과 화면 |
| `classroom.css` | 현재 수업 화면의 반응형 스타일 |
| `src/map.js` | 지도·매물 검색·선택 연결 |

이전 버전의 `data/storyline.json`, `historical-facts.json`, `homes.json` 등은 보관 파일이며 현재 진입점에서 읽지 않습니다. 사용 중인 데이터는 `app.js`의 두 fetch 경로를 기준으로 확인하세요.
