# 코드 구조 및 데이터 기준

## 1. 전체 흐름

```text
index.html
 ├─ Leaflet CDN
 ├─ src/state.js          (공유 데이터·페르소나·저장)
 ├─ src/market-model.js   (시나리오, 단지별 연간 가격)
 ├─ src/finance.js        (자금 조달, 대출, 순자산)
 ├─ src/views.js          (HTML 카드와 결과 렌더링)
 ├─ src/map.js            (실제 지도, 가격 핀)
 ├─ src/game.js           (매수·매도, 연도 갱신)
 └─ app.js                (이벤트 연결, 데이터 fetch, 시작)
```

각 파일은 `defer`가 붙은 **classic script**입니다. 최상위 `let`, `const`, 함수들은 같은 페이지의 전역 lexical 환경을 공유합니다. 빌드 도구가 필요 없는 대신 파일 사이에 함수 의존성이 있으며, 로드 순서를 유지해야 합니다.

## 2. 데이터가 실제인 범위

- 실제: `data/listings.json`의 아파트 이름, 위치 좌표, 면적, 준공연도, 2020년 1~9월 실거래가격 가공 중앙값
- 시뮬레이션: 2021~2026년 단지별 가격과 등락 요인, `data/storyline.json`의 뉴스·금리·공급·미분양 등, 생활권 프로젝트·대출 가정
- 2026년 실제 실거래가격은 게임 결과를 만드는 데 쓰지 않습니다.

실제 국토교통부 자료를 **원본과 대조 재검증하지 않은 상태**이므로, 데이터 수집·필터·집계 방식은 원본을 함께 보관하고 별도로 검증해야 합니다. 아파트 610개는 시장 전체를 대표하는 표본이 아닙니다.

## 3. 가격 모델

- 시작가격: `home.basePrice`
- 연도별 수익률: `breakdown(home, year).total`
- 연도가 하나 지날 때 `price *= (1 + return)`을 적용해 반올림
- `componentsFor`는 지역 충격, 생활권 보정, 시나리오 거래·금리·입주 신호, 가격대·면적·연식 특성, 인근 가상 프로젝트를 합산합니다.
- 변동폭 제한은 연간 대략 -31%~+32%이며 **실증적으로 추정·검증한 값은 아닙니다.**

**게임 결과의 요인 분석은 `componentsFor`의 게임 내 가정에 대한 분해**일 뿐 한국 실제 시장의 인과 설명은 아닙니다.

## 4. 사용자 상태 및 저장

- `session.year`: 2020~2026
- `session.phase`: `decision` 또는 `reveal`
- `session.cash`, `houseId`, `loan`: 현금, 보유 집, 대출 잔액
- `session.transactions`: 거래 내역
- `session.yearly`: 의사결정 기록
- `session.passages`: 연도 전환에 따른 자산 변화
- `localStorage` 키: `housing-time-map-v8-differentiated` (기존 v8 유지)

## 5. UI 구조를 보존한 리팩터링

- 기존 CSS 선택자/선언값/순서를 유지하면서 가독성을 높였습니다.
- 기존 HTML 템플릿의 `<tag><tag>` 사이를 `\\`와 줄 연속 문법으로 나누었습니다. 출력되는 HTML 문자열 자체는 변경되지 않습니다.
- 기존 게임 계산값, 매물 데이터, 시나리오 데이터, 로컬 저장 키는 변경하지 않았습니다.
- 초기 화면, 2020→2021년 진행, 가격 계산의 원본/리팩터링 동등성 검증을 수행했습니다. 모든 브라우저·지도 렌더링 환경까지 완전 검증된 것은 아닙니다.
